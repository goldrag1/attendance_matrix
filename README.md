# Attendance Matrix

Excel-like Attendance Management for ERPNext.

This branch contains the **encrypted release** of the Attendance Matrix application.

## Installation

To install this application on your ERPNext instance, follow these steps:

1.  **Get the App**:
    From your bench directory, run:
    ```bash
    bench get-app https://github.com/goldrag1/erpnext_attendance_matrix.git --branch release-encrypted
    ```

2.  **Install the App to your Site**:
    Replace `[your-site-name]` with your actual site name:
    ```bash
    bench --site [your-site-name] install-app attendance_matrix
    ```

3.  **Restart Bench**:
    ```bash
    bench restart
    ```

## System Requirements

- **Operating System**: Linux (x86_64)
- **Python Version**: 3.12 (standard for Frappe v15)
- **Frappe Version**: v15 or higher recommended
